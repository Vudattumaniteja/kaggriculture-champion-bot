# Master Reward Engineering Blueprint: Macro Potential, Micro Utilities, Grilling Tests & Gym Wrapper

The optimal reward architecture separates macro learning from micro execution: the neural policy learns long-horizon capital allocation via Potential-Based Reward Shaping (PBRS) over 5 enterprise value engines (Cash, Land, Crops, Livestock, Inventory) blended 80/20 with opponent margin, while the deterministic micro solver uses a hardcoded task utility ranking. Reward hacking (the Cobra Effect) and policy paralysis are prevented by rewarding state value rather than action verbs and using pre-softmax action masking instead of negative penalties. The reward function must pass 4 grilling stress-tests (Telescoping Invariance, Loop Farming, Passive Baseline, Monotonic Investment) before online training in the vectorized Gym wrapper.
