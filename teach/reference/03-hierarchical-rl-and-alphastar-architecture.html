3. Mathematical Formulas for Multi-Head PPO Stabilization

GradNorm Dynamic Loss Balancing (Chen et al., 2018)

G_i(t) = || grad_W ( w_i(t) * L_i(t) ) ||_2
r_i(t) = ( L_i(t) / L_i(0) ) / Mean_Loss_Ratio
Target_i = Mean_G * ( r_i(t) )^alpha      # alpha = 0.12
L_gradnorm = sum_i | G_i(t) - Target_i |
Normalize: sum_i w_i(t) = K

1001-Bin Symlog Two-Hot Value Critic (DreamerV3)

symlog(x) = sign(x) * ln(|x| + 1)
L_critic = - sum_{b=1}^{1001} p_target,b * log( Softmax( V_logits )_b )
