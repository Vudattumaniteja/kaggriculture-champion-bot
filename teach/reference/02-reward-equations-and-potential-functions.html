1. The Complete Hybrid State Potential Equation

The state potential function for player $p$ at step $t$ is:

Phi(s_t, t, p) = Cash_t + Phi_crop(s_t, t) + Phi_animal(s_t, t) + Phi_seed(s_t, t) + Phi_shed(s_t, t) + Phi_land(s_t, t) - Deadweight(t)

The final training target blends absolute net worth and tournament win margin:

Phi_target(s_t, t) = 0.80 * Phi(s_t, t, player) + 0.20 * [ Phi(s_t, t, player) - Phi(s_t, t, 1 - player) ]

3. Python Code Blueprint for pbrs_gae.py

def compute_state_potential(
    obs: Dict[str, Any],
    player: int = 0,
    total_turns: int = 720,
    alpha_abs: float = 0.8,
    alpha_rel: float = 0.2,
    deadweight_penalty_coeff: float = 1.0,
) -> float:
    \"\"\"Computes 80/20 hybrid absolute/relative potential.\"\"\"
    phi_player = _compute_player_net_worth(obs, player, total_turns, deadweight_penalty_coeff)
    phi_opp = _compute_player_net_worth(obs, 1 - player, total_turns, deadweight_penalty_coeff)
    
    return alpha_abs * phi_player + alpha_rel * (phi_player - phi_opp)
